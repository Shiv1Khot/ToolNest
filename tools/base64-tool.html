    FAQs

    What is Base64 used for?

    Base64 represents binary data as plain ASCII text, so it's handy for embedding images in code, passing tokens in URLs and headers, and encoding data in JSON or XML.

    Does it support Unicode and emoji?

    Yes. The tool correctly encodes and decodes full UTF-8 text, including accented characters, non-Latin scripts and emoji.

    Is Base64 encryption?

    No — Base64 is just an encoding, not encryption. Anyone can decode it, so never use it to "hide" passwords or secrets.
