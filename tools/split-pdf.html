✂️ Split PDF

Pull specific pages or page ranges out of a PDF into a brand-new file.

e.g. 1-3, 5, 8-10
🔒 Files never leave your browser. Everything is processed locally on your device.

How to use

  1. Drop a PDF onto the upload box — you'll see how many pages it has.
  2. Type the pages you want, like 1-3, 5, 8-10.
  3. Press Extract pages to download a new PDF with just those pages.

FAQs

What can I type in the pages box?

Single pages (5), ranges (1-3), or any mix separated by commas: 1-3, 5, 8-10. Spaces are fine, and duplicate or overlapping entries are tidied up automatically.

Does page numbering start at 0 or 1?

It starts at 1 — the first page of your document is page 1, the second is page 2, and so on.

Is my file uploaded anywhere?

No. This tool runs entirely in your browser — your file is never sent to any server.
