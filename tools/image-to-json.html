    👁️ Image to JSON

    Run OCR on an image and get the extracted text as JSON.

    Waiting for an image…
    🔒 Files never leave your browser. Everything is processed locally on your device.

    How to use

    1. Drop a photo or screenshot containing text into the box above.
    2. Press OCR to JSON — the image is scanned and its text is packed into a JSON object.
    3. Copy the JSON or download it as a .json file.

    FAQs

    What does the JSON look like?

    A simple object with the source file name and the extracted text, e.g. { "source": "photo.png", "text": "…" } — ready to drop into your code.

    How accurate is the OCR?

    Clear, high-contrast images with straight, well-lit English text work best. Blurry or skewed text produces more errors — cropping tightly around the text helps.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
