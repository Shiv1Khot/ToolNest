    📊 Excel to JSON

    Turn spreadsheet rows into clean JSON objects.

    The first row is used as the object keys.

    🔒 Files never leave your browser. Everything is processed locally on your device.

    How to use

    1. Drop an .xlsx or .xls file onto the box above.
    2. Choose the sheet to convert — its first row becomes the JSON keys.
    3. Click Convert to JSON, then copy or download the result.

    FAQs

    How are the JSON keys decided?

    The first row of the sheet is treated as the header row and becomes the keys of each object. Empty header cells get a fallback key like col_3.

    What about empty cells?

    Empty cells become empty strings ("") in the JSON output, so every object has the same keys.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
