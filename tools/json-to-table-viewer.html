    How to use

    1. Paste a JSON array of objects into the box.
    2. Click Render Table — click any column header to sort.
    3. Download the data as CSV whenever you're ready.

    FAQs

    What if the objects don't all have the same fields?

    All fields are collected into columns and rows that lack a field show an empty cell — nothing is dropped.

    Is there a size limit?

    For speed, the on-screen table caps at the first 500 rows. The CSV download includes every row, no cap.

    Is my data uploaded anywhere?

    No. Rendering happens entirely in your browser — your data is never sent to any server.
