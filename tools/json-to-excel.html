FAQs

What happens to nested objects?

They're flattened one level deep using dot notation — {"address": {"city": "Pune"}} becomes an address.city column. Nested arrays are stored as JSON text in their cell.

Are numbers kept as numbers?

Yes. Numeric values are written as real Excel numbers so formulas and sorting work on them.

Is my data uploaded anywhere?

No. Conversion happens entirely in your browser — your data is never sent to any server.
