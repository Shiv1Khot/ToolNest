    How to use

    1. Paste your JSON into the box above.
    2. Click Validate & Convert — syntax errors are flagged with a plain-English hint.
    3. If it's valid, a pretty-printed data.pdf downloads automatically.

    FAQs

    What does "pretty-printed" mean?

    The JSON is reformatted with 2-space indentation and line breaks before going into the PDF, so nested objects and arrays are easy to read instead of one giant line.

    My JSON failed validation — what now?

    The error message names the problem (often a missing comma or an extra trailing comma). Fix that spot and convert again — the tool won't produce a PDF from invalid JSON.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your JSON is never sent to any server.
