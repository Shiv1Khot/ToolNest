    FAQs

    Why isn't my GIF animated anymore?

    Browsers can read the frames of a GIF but can't write a new animated GIF — there's no GIF encoder built in. So this tool saves the first still frame in a modern, much smaller format instead. If you need to keep the animation, an animated GIF simply can't be re-encoded here.

    Which output is smallest?

    WebP, usually by a wide margin — it compresses better than PNG and keeps transparency unlike JPEG. Pick WebP unless you need the file to open in very old software.

    Is my GIF uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
