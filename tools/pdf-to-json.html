    📄 PDF to JSON

    Extract the text of every PDF page into structured JSON.

    🔒 Files never leave your browser. Everything is processed locally on your device.

    How to use

    1. Drop your .pdf file onto the upload area.
    2. Click Extract to JSON — each page's text is collected in order.
    3. A preview appears above and the full .json file downloads automatically.

    FAQs

    My PDF came out empty — why?

    Scanned PDFs are images, not text, so there's nothing to extract. Try the PDF to Text (OCR) tool instead — it reads scanned pages visually.

    Is the layout preserved?

    No. The JSON holds plain running text per page — column positions, fonts, and table structure are not preserved. It's built for data processing, not faithful re-creation.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
