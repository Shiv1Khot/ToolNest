    FAQs

    How are arrays handled?

    Each array item becomes a repeated <item> element inside the parent — for example, {"tags": ["a", "b"]} becomes <tags><item>a</item><item>b</item></tags>.

    What if my JSON keys aren't valid XML names?

    They're cleaned up automatically: spaces and special characters become underscores, and names that would be invalid get a leading underscore.

    Is my data uploaded anywhere?

    No. Conversion happens entirely in your browser — your data is never sent to any server.
