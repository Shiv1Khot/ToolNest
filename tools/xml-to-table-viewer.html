    How to use

    1. Paste XML with repeating record elements (like <contact> inside <contacts>).
    2. Click Render Table — the most repeated element is picked as the record.
    3. Download everything as CSV when you're ready.

    FAQs

    How does it pick the record element?

    It counts the child element names directly under the root and picks the most repeated one. Each record's own child elements (and attributes) become columns.

    What if records have different children?

    All child names are collected into columns and records that lack one show an empty cell — nothing is dropped.

    Is my data uploaded anywhere?

    No. Rendering happens entirely in your browser — your data is never sent to any server.
