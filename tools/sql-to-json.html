    Parse SQL INSERT statements back into clean JSON.

    How to use

    1. Paste your INSERT INTO … VALUES statement into the box.
    2. Click Parse to JSON.
    3. Copy the JSON or download it as a file.

    FAQs

    What SQL does this understand?

    Standard single and multi-row INSERT statements like INSERT INTO users (name, age) VALUES ('Ada', 36), ('Alan', 41);. It is not a full SQL parser — SELECTs, UPDATEs, joins and dialect-specific syntax are out of scope.

    What happens to NULL, TRUE and numbers?

    NULL becomes JSON null, TRUE/FALSE become JSON booleans, and numeric literals stay numbers. Quoted strings become JSON strings.

    Is my data uploaded anywhere?

    No. Parsing happens entirely in your browser — your data is never sent to any server.
