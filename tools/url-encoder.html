    🔗 URL Encoder / Decoder

    Percent-encode URLs for safe transport, or decode them back to readable form.

    How to use

    1. Paste the URL or text you want to convert.
    2. Choose URI component for a query value, or Full URL for a complete address.
    3. Click Encode or Decode, then copy the result.

    FAQs

    When should I use "URI component" vs "Full URL"?

    Use URI component when encoding a single value (like a search term) that will sit inside a URL — it encodes characters like & and ? that would otherwise break the address. Use Full URL when encoding a complete address and you want its structure preserved.

    Why do some characters become %20?

    URLs can only safely contain a limited character set. Percent-encoding replaces unsafe characters (like spaces) with a % followed by their code — %20 is a space.

    Can I decode a URL someone sent me?

    Yes — paste the encoded URL and click Decode to get the readable version back.
