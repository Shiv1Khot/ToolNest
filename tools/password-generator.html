    How to use

    1. Drag the slider to set password length (16+ recommended).
    2. Tick the character sets you want included.
    3. Click Generate password — a new random password appears every click.
    4. Copy it and paste it into your password manager.

    FAQs

    Are these passwords truly random?

    Yes — they are generated with your browser's cryptographic random number generator (crypto.getRandomValues), the same source of randomness used for security-sensitive operations on the web.

    Do you store my passwords?

    No. Passwords are created locally in your browser and are never transmitted or saved anywhere. Once you leave the page, they're gone.

    What makes a password strong?

    Length matters most. A 16-character password using all four character sets has far more possible combinations than any attacker can guess — the strength meter estimates this as "bits of entropy".
