FAQs

Will compressing reduce my PDF's quality?

No. This tool repacks the file's internals without touching the actual content — text stays the same and images aren't downsampled. How much a file shrinks depends on how it was made: documents with lots of text usually slim down more than image-heavy scans.

My file barely got smaller. Why?

Some PDFs are already well optimized, so there's little redundancy left to remove. A file that was exported with tight compression settings will usually come back almost the same size.

Is my file uploaded anywhere?

No. This tool runs entirely in your browser — your file is never sent to any server.
