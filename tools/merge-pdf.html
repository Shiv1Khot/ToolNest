📚 Merge PDF

Combine several PDFs into one document, in whatever order you like.

    🔒 Files never leave your browser. Everything is processed locally on your device.

    How to use

    1. Add two or more PDFs using the upload box above — add them all at once or one at a time.
    2. Reorder them with the ↑ and ↓ buttons. The top file becomes the first pages of the result.
    3. Press Merge PDFs to download the combined document.

    FAQs

    How do I control the page order?

    Use the ↑ and ↓ buttons on each file in the list. The top item lands first in the merged document. Hit ✕ to drop a file from the merge without affecting the others.

    Are bookmarks and links kept?

    No. Pages are copied into a brand-new document, so bookmarks, outlines, and form fields don't carry over — but the page content itself stays intact.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
