Turn a JSON array into CREATE TABLE and INSERT statements.

Paste a JSON array or a single object.

🔒 Files never leave your browser. Everything is processed locally on your device.

How to use

  1. Paste your JSON into the box above and set a table name.
  2. Click Generate SQL.
  3. Copy the script or download it, then run it in your database.

FAQs

How are column types chosen?

The generator looks at every value: all-integer columns become INTEGER, other numbers become REAL, and everything else becomes TEXT.

Will this run on any database?

The output uses standard SQL (CREATE TABLE + INSERT) that works in SQLite, PostgreSQL, MySQL and most other databases. True/false values are written as TRUE/FALSE keywords.

Is my data uploaded anywhere?

No. Generation happens entirely in your browser — your data is never sent to any server.
