How to use

  1. Paste a JSON array (or a single object) into the box, or drop a .json file.
  2. Click Convert to CSV — nested objects are flattened with dot-separated names.
  3. Check the preview, then download your CSV.

FAQs

What happens to nested objects?

They're flattened one level deep using dot notation — so {"address": {"city": "Pune"}} becomes a column called address.city. Nested arrays are stored as JSON text inside their cell.

What if some objects have extra fields?

All columns are collected from every object, and rows that lack a field get an empty cell — nothing is lost.

Is my data uploaded anywhere?

No. Conversion happens entirely in your browser — your data is never sent to any server.
