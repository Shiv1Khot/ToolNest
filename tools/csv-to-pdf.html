    📄 CSV to PDF

    Turn a CSV file into a neatly formatted PDF table.

    Match the separator your file uses — European exports often use semicolons.
    🔒 Files never leave your browser. Everything is processed locally on your device.

    How to use

    1. Drop your CSV file (or a .txt export) onto the upload area above.
    2. Pick the delimiter your data uses — comma, semicolon, or tab.
    3. Hit Convert to PDF and a print-ready table.pdf downloads automatically.

    FAQs

    Which delimiter should I choose?

    Most CSV files use commas. If your file came from a spreadsheet set to a European locale, it probably uses semicolons. Tab-separated files are common in database exports. If the table looks wrong, just try another delimiter and convert again.

    What happens to very long cell text?

    Cells are truncated with an ellipsis (…) so every column stays visible on the page. The tool keeps as much text as fits the column width — it's designed for readable printouts, not full-data dumps.

    Is my file uploaded anywhere?

    No. This tool runs entirely in your browser — your file is never sent to any server.
